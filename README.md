# CoV 시연판

음악·디자인 외주 거래 1건이 **계약 조건 확정 → 입금 → 작업·수정 → 검수 → 지급 → 정산**까지 어떻게 흘러가는지 클릭으로 보여 주는 시연판(데모)입니다.

- **DB와 서버가 없습니다.** 데이터는 내 브라우저(localStorage)에만 저장되고, 처음 열면 가상 예시 거래가 들어갑니다.
- 화면에 나오는 이름·계좌·거래는 모두 **가상**입니다.
- 이메일 알림, PDF 발송, 파일 업로드, 장부 동기화는 모두 **흉내**만 냅니다. 실제로는 아무것도 보내지 않습니다.

## 둘러보기

화면 위쪽의 **작업자 / 의뢰인 / 운영자** 버튼으로 역할을 바꿉니다. 로그인은 없습니다.

1. **작업자**: `+ 새 계약 생성`에서 조건을 입력하고 확인 요청을 보냅니다.
2. **의뢰인**: 조건에 동의합니다. 조건이 잠기고 SHA-256 해시와 동의 시각이 기록됩니다.
3. **의뢰인**: `이체했어요`를 누릅니다.
4. **운영자**: 입금을 확인합니다.
5. **작업자**: 납품을 제출합니다. **의뢰인**은 수정을 요청하거나 검수를 승인합니다.
6. **운영자**: 지급을 완료하면 정산이 끝납니다.

`시연 도구`에서 시간을 빨리 감거나 데이터를 처음 상태로 되돌릴 수 있습니다.

## 로컬 실행

Node.js 20 이상.

```bash
npm install
npm run dev        # http://localhost:3000
npm test
npm run build      # 정적 파일이 out/ 에 생김
```
